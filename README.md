# KW-Chatbot

For KW Chatbot Project, here we define conda environment:
```
conda create -n chatbot python=3.11.7 pip
```

We recommend using miniconda settings instead of default python virtual environment.


For dependecy configuruation, 

```
pip install -r requirements.txt
```

Every data directory will be named under 'data,' we recommend creating a directory named same as data so as to not experience any directory issue within src code.
